# TenderLens input template

Copy this into a Sokosumi task or the Masumi `start_job` request and replace the brackets.

```text
Tender / opportunity title: [title]
Buyer / contracting authority: [name]
Geography: [country / region]
Deadline: [date, if known]
Contract value / budget: [value, if known]

Scope and requirements:
[paste the tender summary or requirements]

Our offer and capabilities:
[what we sell, past experience, certifications, capacity]

Known competitors or alternatives:
[names or "unknown"]

Decision required:
[bid / no-bid, positioning strategy, competitor analysis, etc.]
```
